# 🦊 EnglishAI Tutor

An interactive desktop English language learning application powered by AI, built with **Python** and **PyQt5**.

---

## 🎨 Features & Visual Design
- **Custom GUI:** Elegant interface styled in deep burgundy (`#80323C`) and dark purple (`#1B1528`) themes with vibrant lilac text accents (`#D0A9DE`).
- **Interactive UI:** Atmospheric visual components with fox characters 🦊.
- **Adaptive Modes:** Exercises tailored for various skill levels (Beginner, Intermediate, Advanced).

---

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **GUI Framework:** PyQt5
- **Version Control:** Git / GitHub
